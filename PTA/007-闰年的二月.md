# 007 闰年的二月

**来源**：PTA LX214 &nbsp;|&nbsp; **难度**：简单 &nbsp;|&nbsp; **标签**：`数学` `技巧`

---

## 题目描述

普通的二月有 28 天，闰年的二月有 29 天。

这个题目中严禁使用 `if` 或问号表达式等条件判断语句。

---

## 输入格式

`true` 或 `false`，表示年份是否为闰年。

## 输出格式

二月的天数。

---

## 样例

**样例输入**

```
true
```

**样例输出**

```
29
```

**样例输入**

```
false
```

**样例输出**

```
28
```

---

## 思路

题目要求不能使用 if 或条件判断语句。代码巧妙地利用了布尔值到整数的隐式转换：`bool` 类型的 `true` 相当于整数 1，`false` 相当于 0。先设 `moon = 28`，然后 `moon += b`，闰年时 b 为 true（即 +1）得到 29 天，平年时 b 为 false（即 +0）保持 28 天。使用 `boolalpha` 读取字符串 "true"/"false" 为布尔变量。

---

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    bool b;
    int moon = 28;
    cin >> boolalpha >> b;
    moon += b;
    cout << moon << endl;
    return 0;
}
```
