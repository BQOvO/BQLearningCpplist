# 002 兰那罗们的游戏2

**来源**：PTA 3 &nbsp;|&nbsp; **难度**：简单 &nbsp;|&nbsp; **标签**：`模拟` `数学`

---

## 题目描述

兰那罗们又来找旅行者玩游戏了，这次他们打算玩数学游戏。

旅行者不喜欢被三整除的数字，也不喜欢十进制里三结尾的数字。因此旅行者写下来他喜欢的数字：

1, 2, 4, 5, 7, 8, 10, 11, 14, 16, ……

请你写出第 k 个旅行者喜欢的数字。

---

## 输入格式

第一行包含一个整数 t（1 < t < 100）—— 测试用例的数量。

然后是 t 个测试用例，每个测试用例包含一行包含一个整数 k（1 < k ≤ 1000）。

## 输出格式

对于每个测试用例，在单独的行中输出一个整数 a —— 序列的第 k 个元素。

---

## 样例

**样例输入**

```
10
1 2 3 4 5 6 7 8 9 1000
```

**样例输出**

```
1 2 4 5 7 8 10 11 14 1666
```

---

## 思路

题目要求生成一个序列，该序列排除了所有**被 3 整除**以及**十进制末位为 3** 的数。代码的思路是**预处理打表**：预先枚举 1~2000 的所有数，将满足条件（n%3!=0 且 n%10!=3）的数依次存入数组 p 中，相当于构建了一个"喜欢数字"的映射表。之后对每个查询 k，直接输出 p[k] 即可，单次查询 O(1)。

---

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int nums, t[1000], p[100000];
    cin >> nums;
    for (int i = 0; i < nums; i++) cin >> t[i];
    int m = 1;
    for (int n = 1; n <= 2000; n++) {
        if (n % 3 != 0 && n % 10 != 3) p[m++] = n;
    }
    for (int l = 0; l < nums; l++) {
        if (l != 0) cout << endl;
        printf("%d", p[t[l]]);
    }
    return 0;
}
```
