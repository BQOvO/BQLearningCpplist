# 017 列队报数一

**来源**：PTA 32 &nbsp;|&nbsp; **难度**：中等 &nbsp;|&nbsp; **标签**：`模拟` `数组`

---

## 题目描述

同学们正在练习列队，从第一个人开始按编号 1、2、…、n（n < 1000）报数，开始所有人都是面向前方。

- 第一遍报数是 3 的倍数的同学执行一遍向后转命令；
- 第二遍报数是 4 的倍数的同学执行一遍向后转命令；
- 第三遍报数是 5 的倍数的同学执行一遍向后转命令。

只考虑面向前方的同学向后转，不考虑已经向后转的同学再向前转的情况。

输入人数 n，按顺序输出最终仍然面向前方的同学的编号。

---

## 输入格式

输入一个正整数 n。

## 输出格式

在一行中输出一个整数列，以空格间隔。

---

## 样例

**样例输入**

```
10
```

**样例输出**

```
1 2 7
```

---

## 思路

用数组 nums 标记每个同学的状态（1 表示面向前，-1 表示面向后）。初始全部为 1。依次进行三轮筛选：报数是 3 的倍数者翻转状态（nums[i] = -nums[i]），同理处理 4 的倍数和 5 的倍数。注意题目说的"只考虑面向前方的同学向后转"，即执行向后转命令就是翻转状态（不管之前状态如何）。最后输出所有状态为 1 的编号，并在编号间智能添加空格（只在后面还有面向前的同学时输出空格）。

---

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int nums[1000];
    int r;
    scanf("%d", &r);
    for (int i = 1; i <= r; i++) nums[i] = 1;
    for (int n1 = 1; n1 <= r; n1++)
        if (n1 % 3 == 0) nums[n1] = -nums[n1];
    for (int n2 = 1; n2 <= r; n2++)
        if (n2 % 4 == 0) nums[n2] = -nums[n2];
    for (int n3 = 1; n3 <= r; n3++)
        if (n3 % 5 == 0) nums[n3] = -nums[n3];
    for (int n4 = 1; n4 <= r; n4++) {
        if (nums[n4] == 1) {
            printf("%d", n4);
            for (int n5 = n4 + 1; n5 <= r; n5++)
                if (nums[n5] == 1) { printf(" "); break; }
        }
    }
    return 0;
}
```
