# 015 输出指定范围内的素数

**来源**：PTA 29 &nbsp;|&nbsp; **难度**：简单 &nbsp;|&nbsp; **标签**：`数学` `素数`

---

## 题目描述

输入两个大于 1 的正整数 A, B（A < B），然后输出这两个数范围内的所有素数。

---

## 输入格式

输入两个整数 A 和 B。

## 输出格式

输出 A 和 B 之间的所有素数。例如，a1,a2,a3（逗号分隔）。

---

## 样例

**样例输入**

```
2 10
```

**样例输出**

```
2,3,5,7
```

---

## 思路

与 011 类似，使用**试除法**判断素数。Prime 函数对 2 和 3 直接返回真，对其他数统计因子个数，恰好为 2 则是素数。主函数遍历区间 [A, B]，将素数存入数组 prime，最后遍历数组按格式输出，用逗号分隔（第一个前不加逗号）。

---

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int Prime(int n) {
    int nums = 0;
    if (n == 2 || n == 3) return 1;
    for (int i = 1; i <= n; i++)
        if (n % i == 0) nums++;
    return nums == 2;
}

int main() {
    int a, b, c = 0;
    int prime[10000];
    scanf("%d %d", &a, &b);
    for (int l = a; l <= b; l++)
        if (Prime(l)) prime[c++] = l;
    for (int j = 0; j < c; j++) {
        if (j != 0) printf(",");
        printf("%d", prime[j]);
    }
    return 0;
}
```
