# 013 输出所有因数

**来源**：PTA 25 &nbsp;|&nbsp; **难度**：简单 &nbsp;|&nbsp; **标签**：`数学`

---

## 题目描述

输入一个整数，输出其所有因数。

例如：输入 10，输出 1、2、5 和 10。

---

## 输入格式

输入一个正整数（小于 10⁵）。

## 输出格式

由小到大输出各因数，使用空格为分隔，结尾有空格。

---

## 样例

**样例输入**

```
10
```

**样例输出**

```
1 2 5 10
```

---

## 思路

因数（约数）是指能整除给定数的正整数。代码采用**暴力枚举**法：从 1 到 nums 遍历每个整数 i，若 nums % i == 0 则 i 为因数，直接输出。时间复杂度 O(n)，对于 n < 10⁵ 可以接受。更高效的做法是只枚举到 √n，同时输出成对的因数。

---

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int nums;
    scanf("%d", &nums);
    for (int i = 1; i <= nums; i++) {
        if (nums % i == 0) printf("%d ", i);
    }
    return 0;
}
```
