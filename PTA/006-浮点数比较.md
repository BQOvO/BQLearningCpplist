# 006 浮点数比较

**来源**：PTA LX211 &nbsp;|&nbsp; **难度**：中等 &nbsp;|&nbsp; **标签**：`数学` `浮点数`

---

## 题目描述

输入三个浮点数 a, b, c，判定 a − b 和 c 是否相等。a, b, c 的精度均为 10⁻⁴。

注意：本题禁止使用分支结构。

---

## 输入格式

一行，输入三个浮点数 a, b, c，以逗号分隔。

## 输出格式

`true` 或 `false`

---

## 样例

**样例输入**

```
2.2226, 2.2224, 0.0002
```

**样例输出**

```
true
```

#include <bits/stdc++.h>
