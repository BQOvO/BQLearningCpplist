# 006 浮点数比较

**来源**：PTA LX211 &nbsp;|&nbsp; **难度**：中等 &nbsp;|&nbsp; **标签**：`数学` `浮点数`

---

## 题目描述

输入三个浮点数 a, b, c，判定 a − b 和 c 是否相等。a, b, c 的精度均为 10⁻⁴。

注意：本题禁止使用分支结构。

---

## 输入格式

一行，输入三个浮点数 a, b, c，以逗号分隔。

## 输出格式

`true` 或 `false`

---

## 样例

**样例输入**

```
2.2226, 2.2224, 0.0002
```

**样例输出**

```
true
```

---

## 思路

浮点数在计算机中无法精确表示，直接比较两个浮点数是否相等往往会因舍入误差导致误判。代码采用**容差比较**法：判断 |(a−b) − c| < ε 是否成立，其中 ε = 10⁻⁵（比题目精度 10⁻⁴ 更严格一位以确保安全）。同时使用 `boolalpha` 将布尔值直接输出为 `true`/`false`，避免了分支结构，满足题目要求。

---

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double a, b, c;
    scanf("%lf,%lf,%lf", &a, &b, &c);
    cout << boolalpha << (fabs((a - b) - c) < 1e-5) << endl;
    return 0;
}
```
