# 010 时间流逝

**来源**：PTA LX220 &nbsp;|&nbsp; **难度**：中等 &nbsp;|&nbsp; **标签**：`数学` `模拟`

---

## 题目描述

输入天、小时、分，然后再给定一个流逝的分钟数，计算最后的时间。

其中小时数用 24 小时表示。

**注意**：不允许使用条件判断语句。

---

## 输入格式

输入有两行。

第一行为 3 个正整数，分别表示天、小时、分，用冒号分隔；

第二行为一个正整数，表示流逝的分钟数。

## 输出格式

求时间流逝后的天、小时、分，用冒号分隔。

---

## 样例

**样例输入**

```
7:16:5
61
```

**样例输出**

```
7:17:6
```

---

## 思路

将所有时间统一转换为**以分钟为单位的绝对时间**，避免跨天、跨时的复杂进位运算。先将当前时间（天、时、分）转换为总分钟数 `total = d×1440 + h×60 + f + n`，然后通过整除和取模分别还原出天、时、分：天数 = total/1440，小时 = (total%1440)/60，分钟 = (total%1440)%60。整个过程无需条件判断，只需算术运算。

---

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int d, h, f, n;
    scanf("%d:%d:%d", &d, &h, &f);
    scanf("%d", &n);
    int total = d * 1440 + h * 60 + f + n;
    int d1 = total / 1440;
    int rem = total % 1440;
    int h1 = rem / 60;
    int f1 = rem % 60;
    printf("%d:%d:%d\n", d1, h1, f1);
    return 0;
}
```
