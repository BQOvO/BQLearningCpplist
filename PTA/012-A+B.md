# 012 A + B ?

**来源**：PTA 23 &nbsp;|&nbsp; **难度**：中等 &nbsp;|&nbsp; **标签**：`数学` `博弈论`

---

## 题目描述

两个玩家使用一个共 n 个石子的石堆进行回合制游戏，两个玩家依次严格拿走 a 或 b 个石子，如果到了哪个玩家的轮次且其无法拿走满足要求的石子数则判其负。

给出 a, b，求任意一个 n 使得后手玩家必胜。

---

## 输入格式

多组数据。第一行一个整数 T 表示数据组数。

接下共 T 行，每一行两个整数，表示 a, b。

## 输出格式

对于每组数据，输出共一个整数，表示 n。

---

## 样例

**样例输入**

```
3
1 4
1 5
9 26
```

**样例输出**

```
2
6
8
```

**数据范围**：0 ≤ T, a, b ≤ 1000，题目保证 [0, 10000] 中存在符合要求的 n，请不要输出过大的 n。
