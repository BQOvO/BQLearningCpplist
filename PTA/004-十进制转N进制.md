# 004 十进制转N进制

**来源**：PTA LX208 &nbsp;|&nbsp; **难度**：简单 &nbsp;|&nbsp; **标签**：`数学` `进制转换`

---

## 题目描述

给定一个三位的十进制数，转换为 N 进制数。

---

## 输入格式

一行，两个数 v 和 N，空格分隔。N 表示 N 进制（2 ≤ N ≤ 9），v 是一个十进制数值。

## 输出格式

对应的 N 进制数。

---

## 样例

**样例输入**

```
214 9
```

**样例输出**

```
257
```

**提示**：2×10² + 1×10¹ + 4×10⁰ = 2×9² + 5×9¹ + 7×9⁰

---

## 思路

十进制转 N 进制采用经典的**除基取余法**：反复对 N 取余得到当前最低位的数字（存入数组），然后将原数除以 N（整数除法）继续处理，直到原数变为 0。最后将数组中的余数**逆序输出**，即得到 N 进制的表示。代码中专门处理了 v=0 的边界情况（直接输出 "0"）。

---

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int nums, n, p, l = 0;
    int a[100];
    scanf("%d %d", &nums, &n);
    if (nums == 0) {
        printf("0");
    } else {
        while (nums != 0) {
            p = nums % n;
            nums = nums / n;
            a[l] = p;
            l++;
        }
    }
    for (int i = l - 1; i >= 0; i--) printf("%d", a[i]);
    return 0;
}
```
