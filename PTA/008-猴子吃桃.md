# 008 猴子吃桃

**来源**：PTA LX216 &nbsp;|&nbsp; **难度**：中等 &nbsp;|&nbsp; **标签**：`数学` `逆推`

---

## 题目描述

一只猴子在树上摘了若干个桃，当即吃了 x%，觉得不过瘾，又多吃了一个；

第二天它吃了剩下桃子的 x% 加一个；

第三天它又吃了剩下桃子的 x% 加一个，此时，只剩下一个桃子。

请编程求解：猴子第一天从树上摘得多少个桃子？

---

## 输入格式

一个整数 x（0 < x < 100）。题目确保每天的桃数为整数。

## 输出格式

输出第一天的桃子数量，题目确保为整数。

---

## 样例

**样例输入**

```
50
```

**样例输出**

```
22
```

**样例输入**

```
99
```

**样例输出**

```
2010100
```

> **提示**：先乘后除，避免浮点精度丢失；可用 `round` 函数取整。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double x, nums = 1;
    cin >> x;
    x = x / 100;
    for (int n = 0; n < 3; n++) {
        nums = (nums + 1) / (1 - x);
    }
    printf("%.0lf\n", nums);
    return 0;
}
```
